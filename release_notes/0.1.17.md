# Facet Launcher 0.1.17

## New Features
- Added a "System bar icons" setting (Appearance → General) to control the color of the status bar and navigation bar icons, so they stay readable over light wallpapers. Choose between Match theme, Light, or Dark.
- Clock adjust mode now has an Alignment option (left, center, right), in addition to height and scale.
- Added a hint that shows you can press and hold the clock to resize or move it.

## Fixes
- Fixed the "make Facet your home screen" prompt showing up even when Facet was already the default launcher; it now goes straight to the gesture hints in that case.
- Fixed the app list sometimes scrolling incorrectly when the list had overflowed.
- Fixed the "Got it" button on the gesture hints being nearly invisible against its background.
- Fixed the Home button sometimes silently stopping working, requiring a restart to fix.
- Fixed the "make Facet your home screen" prompt's button sitting flush against the on-screen navigation buttons on devices with 3-button navigation.
- Fixed a visual inconsistency where the clock adjustment menu showed a strip of background scrim under the navigation bar, unlike other menus.

## Improvements
- Trimmed extra blank space at the bottom of the app drawer so the list scrolls closer to the search bar.
- The clock resize handle is now easier to see against any wallpaper.
- Added a System settings shortcut to the drawer's overflow menu.
- Removed the contrast-boosting overlay behind the status and navigation bars on newer Android versions for a cleaner look.

## Internal
- Extracted drawer overflow menu into its own component (DrawerSearchOverflowMenu).
- Reworked app-list bounds reporting to use snapshotFlow instead of SideEffect.
- Added ThemedModalBottomSheet component and migrated clock, app, and folder menus to it; added DismissOnHomePress and wired it into context menus and sheets.
- Reworked Home-press handling so each UI layer closes independently instead of sharing one collector susceptible to cancellation.
- Removed leftover debug logging (SCROLLPROBE and per-pointer-event tracing) and its associated test.
- Added tests: ClockAdjustToolbarTest, HomeScreenTest coverage for alignment pill, HomeViewModelTest coverage for facet vs global writes; updated gesture-hint test for four hints; updated scrim-tap test to a Back-press test.
- Updated CAPABILITIES.md, CLAUDE.md, IMPLEMENTATION_PLAN.md, design README, PRD, and marked CLOCK_RESIZE_SPEC.md historical.
- Updated knowledge graph (multiple commits).
- Rewrote Play Store listing copy and rebuilt screenshots via new build_screenshots.py script.
- Added detekt baseline entries for new CompositionLocals; removed obsolete baseline entries.
- Bumped version to 0.1.16 (17).
