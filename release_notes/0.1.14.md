# Facet Launcher 0.1.14

## New Features
- **Two-Column & Grid Home Layouts**: Home's app list can now display as two columns or a grid (choose 4, 5, or 6 columns), in addition to the original single column — each layout has its own alignment and icon/text display options in Settings → Appearance.
- **More Favorites**: The favorites limit increased from 6 to 12 apps.
- **Facet Deep Links & Shortcuts**: Facets can now be switched to via deep links and long-press home-screen shortcuts, so jumping straight to a specific facet is one tap away.

## Fixes
- Fixed the Home app list not scrolling when it had more apps than fit on screen — it used to always try to open the Drawer instead.
- Fixed the first-time gesture-hint overlay showing hard-to-read text in light theme.
- Fixed the Appearance and facet-switcher preview cards not showing all configured favorites in the new two-column/grid layouts, and packing an incomplete row's icons unevenly instead of to the left.
- Fixed the facet-switcher preview always showing a single-column list, even for a facet set to two-column or grid.
- Fixed calendar events not centering correctly when center alignment was selected.

## Improvements
- The Facet Settings screen's header button now shows a checkmark and "Active" when that facet is currently applied, or "Activate" otherwise.
- Removed the "Favorites/Recents/Most Used" heading above Home's app list and the "Preview" label on settings preview cards, for a cleaner look.

## Internal
- Room schema migration (v24→v25) for the new per-facet layout fields; backup export/import extended to cover them.
- Restored a Room schema export file that had been silently corrupted during development.
- Added extensive new unit and instrumented test coverage for the layout feature and its fixes, including `FacetSettingsViewModelTest` (20 cases); regenerated the test registry and the knowledge graph.
- Updated architecture docs to match the new layout feature and fixes.
