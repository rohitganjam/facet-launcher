# Facet Launcher 0.1.13

## New Features
- (none)

## Fixes
- **Clock Contrast Fix**: Fixed low-contrast digits on the "Negative Panel" and "Hour Tile" clock styles when using the inverted theme — text now stays readable in both variants.
- **Calendar Centering Fix**: Fixed the calendar events list rendering off-center instead of as one centered block when center alignment was selected.

## Improvements
- **Faster Long-Press Menus**: Long-pressing an app or folder now opens its menu the moment you feel the haptic buzz, instead of waiting until you lift your finger.
