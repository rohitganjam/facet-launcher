# Facet Launcher 0.1.12

## New Features
- **Facet-Symmetric Appearance Overrides**: Dock and app-list display style and position are now dual-mode (global + per-facet with `LAUNCHER_DEFAULT` sentinel overriding). Each facet settings destination now owns its own Inherit/Override switch.
- **New Fonts**: Added Montserrat, Lato, and Inter font families for both clock/calendar widgets and launcher-wide typography, with localized font name strings for German, Spanish, French, and Portuguese.

## Fixes
- **Adjust-Mode Gesture Fix**: Fixed a gesture-detector reuse bug during clock adjust-mode transitions that could cause stale touch handlers to linger.

## Improvements
- **Appearance Screen Redesign**: Redesigned the Appearance settings screen into three distinct cards (Dock & Home / Clock / General) with live data sourcing in the preview card (favorites, dock, and calendar events).
- **Clock Accessory Polish**: Polished the `RobotoFlexNarrow` clock template with lighter weight, size-tracking optical sizing, and vertically stacked alarm/battery accessories.

## Internal
- Added SIL Open Font License files for all bundled third-party fonts.
- Updated knowledge graph and test registries.
- Bumped version code to 13 and version name to 0.1.12.
