# Facet Launcher 0.1.18

## New Features
- Facet automation: set up rules that automatically switch your active facet based on a schedule, Wi-Fi network, Bluetooth connection, headphones, or battery level (rules show as unavailable if a needed permission isn't granted). Manage rules from the new "Facet automation" entry in Settings.
- Added a dedicated Facet Pro screen for upgrading, viewing your unlocked status, and restoring previous purchases.
- You can now create up to 10 facets with Facet Pro; the free plan is capped at 3, with extra facets shown locked and marked with a Pro badge.
- Using a custom widget in a facet's clock slot now requires Facet Pro (facets that already had one keep it even if Pro lapses).
- Added an icon shape setting (Squircle, Rounded, Circle, or Square) in Appearance.

## Fixes
- Home screen text (clock, calendar, shortcuts row, app labels) now has a visible shadow so it stays readable on light wallpapers.
- Day labels now correctly reflect your device's language/locale.
- Location permission requests now ask for precise and approximate access together, since recent Android versions ignore a precise-only request.
- Clarified the "Use other apps" note in automation to say whose rules it refers to.

## Improvements
- Going back now slides the previous screen in on every screen, instead of the system's default shrink/zoom animation.
- Redesigned the Facet Pro screen with a more compact layout and a single "Unlock Lifetime Pro" button that shows the price.
- Refreshed the Pro card in Settings with clearer copy and a new icon.
- The automation free-plan upgrade banner now only appears once you hit your rule limit, instead of always showing.
- Cleaner automation rule editor: pill-style tabs for conditions, an inline toggle for "Switch to" rules, and tidier buttons.
- Remaining round buttons across the app now use the same rounded-square shape as the rest of the UI.
- Added missing translations for automation screens.
- Moved the clock style option (with live preview) into the Appearance screen instead of Facet settings.
- Added Bluetooth and Location rows to the Permissions screen.

## Internal
- Upgraded Kotlin to 2.4.10 and KSP to 2.3.12.
- Upgraded Gradle to 9.8.0 and the Android Gradle Plugin to 9.4.1.
- Batch-upgraded libraries (Compose BOM, Navigation, Lifecycle, Activity, Core, Room, Hilt navigation, kotlinx-serialization, Robolectric, Mockito, test orchestrator, compose-rules, benchmark, UI Automator) and bumped compileSdk to 37.
- Integrated Play Billing with a cached entitlement DataStore; added a Gradle check that fails the build if the billing library reintroduces the INTERNET permission.
- Added a debug-only Pro entitlement override for testing.
- Built out the automation backend: evaluator/state model, rule storage (DB v26), schedule/trigger validation, device trigger sources (battery, headphones, Wi-Fi, Bluetooth), and the rule runner/wake scheduling.
- Routed manual facet switches through a single use case that also suppresses automation rules and records baseline state.
- Refactored ProPill and the upgrade sheet into shared components.
- Updated architecture docs, capabilities doc, privacy policy copy, design handoff, Play Store listing, and generated knowledge graph to match the code.
- Fixed stale instrumented tests (facet-scoped Appearance test, favorites cap test) and updated the detekt baseline.
- Fixed an unparseable sequence diagram in the deep-links doc.
- Added planning docs for Facet Pro billing/facet cap and for facet automation.
- Bumped version to 0.1.17 (code 18) and added its release notes.
- Added icon shape as an additive backup field (no version bump).
