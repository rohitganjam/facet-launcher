
# Facet Launcher 0.1.19

## New Features
- (none)

## Improvements
- **A new look for Settings.** Settings, per-facet settings, Folders, Backup & restore and the long-press menu on Home now use soft rounded cards with an icon on each row, clear section headings and no arrows. A pressed row highlights across the whole card.
- **Rounded buttons everywhere.** Every button, including text buttons such as Next, Skip and Turn on, is now fully rounded, and so is its tap highlight.
- **Appearance reordered.** Clock Style now comes first in Appearance, and per-facet settings has its own Appearance card, like the main Settings screen. "Clock & Calendar Style" is now just "Clock Style", because calendar styling follows the clock.
- **Icon shape.** The selected icon shape is drawn with a clearer ring and a small gap.
- **Bigger tap targets.** Permission rows and the Inherit / Override choices can be tapped anywhere on the row, not just on the text.
- **Facet automation.** With no rules yet, the screen shows one card with an icon, a message and an Add rule row.

## Internal
- Moved the last inline UI text, including preview samples, into string resources, and removed unused strings and graphics.
- Shared building blocks for the Settings screens (cards, icon badges and buttons), so every screen uses the same components.
- Updated the architecture docs and tests for the new layout.
