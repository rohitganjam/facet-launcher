# Facet Launcher 0.1.11

## New Features
- Each Home screen can now show a widget from another app in place of the built-in clock, keeping the same drag-to-move and resize controls you already use for other widgets.

## Fixes
- Fixed an issue where swiping across an app icon, folder, or dock item could accidentally launch the app underneath your finger.
- Apps inside folders now respond to long-press the same way as icons everywhere else on Home, Dock, and Drawer, including the haptic buzz.
- Fixed a rare bug that could cause a crash when switching work profiles at just the wrong moment.

## Improvements
- Long-pressing an icon on Home, Dock, or Drawer now opens its menu only when you lift your finger (not as soon as the hold is long enough), matching how the Widget Hub already works, and now gives a haptic buzz when the long-press is recognized.

## Internal
- Added Room database schema migration (v20→22) and a Hub-widget-picker-based flow to support the new clock widget feature.
- Fixed flaky instrumented long-press/tap tests in ClockBlockTest by waiting on real timers instead of compose's simulated gesture helpers.
- Reworked 8 composables (AppRow, SingleAppDockIcon, FolderDockIcon, DrawerAppRow, DrawerFolderRow, FolderContentsAppRow, FolderContentsGridTile, FolderContentsSheet's scrim) so their `modifier` parameter lands on the true root view, clearing most of the baselined ModifierNotUsedAtRoot lint findings; left DrawerGridTile/DrawerFolderTile baselined with an explanatory comment after confirming the same change there breaks row-height sizing.
- Added FolderContentsSheetTest covering long-press behavior for folder list rows and grid tiles.
- Moved versioned release notes into a `release_notes/` folder instead of the repo root, and fixed the release script's file staging so those changes actually get committed.
- Release notes generator now also writes a permanent per-version copy instead of only overwriting the latest-release file; backfilled the 0.1.10 copy.
- Updated the knowledge graph (x2).
- Released version 0.1.10.
