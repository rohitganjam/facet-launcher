# 0.1.19

## Improved
- A new look for Settings: Settings, facet settings, Folders, Backup & restore and the long-press menu on Home now use soft rounded cards with an icon on each row and clear section headings. A pressed row highlights across the whole card.
- Every button, including Next, Skip and Turn on, is now fully rounded.
- Clock Style now comes first in Appearance, and facet settings has its own Appearance card, like the main Settings screen. "Clock & Calendar Style" is now just "Clock Style".
- Permission rows and the Inherit / Override choices can be tapped anywhere on the row.
