# 0.1.28

## New
- The Notification settings screen now has a live preview showing your Home list and Dock with sample badges in the style you picked, plus the media player controls.
- The preview tells you when notification access hasn't been granted, with a button to allow it, and when badges and the media player are both turned off.

## Improved
- The widget picker is now sorted by app name, then widget name, so widgets are easier to find.
- With icon-only Home rows, notification badges now sit on the icon's corner instead of trailing beside it.
- Center alignment on Home now centers just the icon and name, so a notification badge no longer shifts the row.
- Settings screens and bottom sheets now keep a steady text size, no longer changing with the in-app Font size and Font weight options.
- Appearance settings are now split into clear Theme, Icons and Fonts sections, with a font preview showing where each text style is used.
- Some Appearance labels have new names: "Launcher Appearance" is now "Appearance", "System bar icons" is now "Status bar icons", and "Match theme" is now "Default".
- The folder contents sheet now matches the app sheet, with a matching header and a smooth slide in and out.
- "Add to folder" in the app sheet now shows a folder icon with a + badge.
