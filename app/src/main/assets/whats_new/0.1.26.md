# 0.1.26

## New
- Redesigned the long-press menu: see and manage an app's notifications right from the menu, with a new "Show notifications in app menu" setting to turn it off.
- The long-press menu now shows Favorites, Dock, and Folder placement as tappable tiles.
- Added a 3-column option for the Home app grid, alongside 4, 5, and 6.
- Added a "What's new" screen (Settings → About) to read what changed in each release.

## Improved
- The media player's progress wave now eases to a flat line when playback is paused or stopped, instead of switching abruptly between styles.
- App shortcuts have been removed from the long-press menu.
