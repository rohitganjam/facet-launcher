# 0.1.36

## New
- Added a "Hide status bar" option that hides the status bar on Home, Hub and Drawer. Swiping down on Home briefly shows it for 3 seconds, and the next swipe opens the notification shade.

## Improved
- Pressing Home while in another app no longer opens the app drawer search by mistake.
- The "General" section in Appearance is now called "Look & Feel", and its first row is now "General settings". It still contains theme, accent color and system bars related controls.
