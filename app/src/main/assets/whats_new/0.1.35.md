# 0.1.35

## New
- **Icon packs:** You can now apply installed icon packs across the whole launcher from Settings → Appearance → Icons, next to the built-in styles.
- **Icon size slider:** A new Icon size setting on the Icons screen lets you scale every app icon on Home, the dock, the drawer and folders from 80% to 120%.
- **Shrink list to fit:** An optional setting that makes Home's app list switch to compact rows to fit without scrolling
- **Icons and text:** The dock and Home's grid can now show a one-line app name under each icon.
- **Search setup in onboarding:** The first-time setup now lets you choose the search bar position and turn on contact and settings search.

## Improved
- Pressing Home while already on Home now opens the app drawer with search ready to type.
- Folders now match the look of wherever you opened them, using the Home or drawer grid or list rows.
- Icon outlines now have a more consistent brightness and thickness across themed and plain icons.
