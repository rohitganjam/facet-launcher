# 0.1.34

## New
- Facet specific widget stacks: Add more than one widget (launcher widget or custom widget) and swipe between them on the home screen.
- Each stack page page keeps its own size and alignment, in portrait and landscape, and you can swipe between pages while adjusting.

## Improved
 The clock's position and size belong to each facet, and "Edit defaults" on the settings cards takes you to the launcher-wide screen.
