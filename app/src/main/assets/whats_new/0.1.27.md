# 0.1.27

## New
- A Work badge now marks Work Profile apps on Home, the Dock, the Home grid, app pickers and app lists.
- The long-press sheet now shows ongoing notifications you can't swipe away, so badge counts match.

## Improved
- Fixed a crash opening an app picker with a Work Profile.
- You can add a Work Profile app even if its personal copy is already placed.
- The Home preview in Appearance now matches your real Home screen.
- Fixed onboarding sometimes appearing for existing users when the app was slow to start.
- Large album art now uses less memory.
